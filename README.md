# Mark-Skills

Codex skills for Amazon advertising strategy, boutique ad execution, Tianji hourly slot monitoring, and Tianji order probability analysis.

## Skills

- `amazon-ad-strategy-playbook`: Amazon ad strategy selection and tactic mix planning.
- `amazon-boutique-ad-execution`: Boutique ad campaign architecture and staged execution SOP.
- `tianji-hourly-slot-monitor`: Hourly slot/rank monitoring and bid response SOP.
- `tianji-order-probability-analyzer`: Order probability, eCPM, competitor comparison, and optimization decisions.

Each skill keeps a concise `SKILL.md` and stores source methodology documents in `references/`.
