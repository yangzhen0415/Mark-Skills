# 校准记忆库

本文件用于记录用户明确要求沉淀的售后写法校准。它不是固定回复库，而是可复用规则库。

## 使用原则

- 只有用户明确说“记住”“更新”“加入模板库”“以后这样写”“以后不要这样写”“把这个规则存进去”时，才新增或更新校准。
- 每次更新前，先把用户纠正抽象成通用规则，不要直接保存整封邮件。
- 每条规则必须写清楚适用场景，避免误用到不相关问题。
- 新规则默认优先于旧规则；旧规则保留，冲突时在旧规则下标记“被 CAL-xxx 覆盖”。
- Amazon 合规红线优先级最高，任何校准都不能覆盖“不索评、不改评、不删评、不医疗承诺、不站外引导、不超政策承诺”。

## 写入格式

```markdown
## CAL-YYYY-MM-DD-001

- 日期：YYYY-MM-DD
- 场景：未膨胀 / 异味 / 太软太硬 / 退货退款 / 差评投诉 / 物流延误 / 其他
- 优先级：高 / 中 / 低
- 用户纠正：用一句话记录用户原始校准含义。
- 通用规则：抽象成以后可复用的判断或写作原则。
- 适用条件：说明以后遇到什么情况使用。
- 推荐表达：
  - 可变表达方向 1
  - 可变表达方向 2
  - 可变表达方向 3
- 避免表达：
  - 不要写的词句或策略 1
  - 不要写的词句或策略 2
- 覆盖关系：无 / 覆盖 CAL-xxxx / 被 CAL-xxxx 覆盖
```
